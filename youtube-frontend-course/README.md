# YouTube Frontend Course

Workspace for following a frontend (HTML / CSS / JS) course.

## Getting started

Open **this folder on its own** so the project-scoped editor config applies only
here — either `File → Open Folder…` → `youtube-frontend-course`, or double-click
`youtube-frontend-course.code-workspace`. (If you open the repo root instead, the
`.vscode/` settings below are not picked up.)

On first open, VS Code prompts to install the recommended extensions:

| Extension | Purpose |
| --- | --- |
| [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) | Serve `index.html` with live reload — click **Go Live** in the status bar |
| [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) | Format HTML / CSS / JS on save |
| [Mithril Emmet](https://marketplace.visualstudio.com/items?itemName=FallenMax.mithril-emmet) | Enhanced Emmet abbreviations |

Prettier is configured to format **only** HTML, CSS, and JS files, and only in
this folder (see `.vscode/settings.json`).
